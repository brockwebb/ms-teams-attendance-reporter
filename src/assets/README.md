# Vendored runtime assets

## `chart.umd.js`

Chart.js 4.4.6 UMD build, fetched from
`https://cdn.jsdelivr.net/npm/chart.js@4.4.6/dist/chart.umd.js`.

Released under the MIT License — see the banner at the top of the file and
the full text at https://github.com/chartjs/Chart.js/blob/master/LICENSE.md.

It is checked in (rather than fetched at runtime) so generated reports work
fully offline. Update by re-running the same `curl` against a newer tag.
