### Architecture
```
data/raw/          → real CSVs (gitignored)
data/synthetic/    → 4 ACNE Corp meeting files, 50 parody characters
config/config.yaml → single YAML config (org name, name pattern, labels, org mapping)
src/parser.py      → two-section Teams CSV parser (handles column mismatch, BOM, multi-row aggregation)
src/enricher.py    → config-driven org classification (YAML or JSON, name regex, org rollup)
src/reporter.py    → self-contained HTML dashboard generator (Chart.js inline, Census colors)
src/cli.py         → entry point: parser → enricher → reporter
output/            → generated reports (gitignored)
```

### Key Design Decisions
- Self-contained HTML (no server, no CDN, works offline)
- Config-driven: swap org_name + name_pattern + org_mapping for any organization
- No PII in output: names stripped from HTML, participant detail table removed
- Census Data Viz Standards palette: teal (#0095A8) for EMP, orange (#FF7043) for CTR
- Synthetic test data uses "ACNE Corp" (legally distinct Looney Tunes parody)
- All code changes go through cc_tasks/ markdown files executed by Claude Code
- cc_tasks are never modified once written; pre-tasks or new tasks only

### Survey Context
This project supports a 12-session Microsoft 365 Copilot training series. There's a separate MS Forms feedback survey (8 questions: supervisory status, AI engagement level, session attended, instructor rating, post-session confidence, "will Copilot improve efficiency" yes/no/not sure, overall rating, open text). The survey and the attendance reporter are separate tools — the survey captures subjective feedback, the reporter captures objective attendance/engagement data.
