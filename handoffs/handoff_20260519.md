## Key Decisions

- **Sub-org aliases over three-level hierarchy.** Dict syntax in sub_orgs (`JTC: NPC`) rolls up sub-units to parent division at display level. Raw `org_code` preserved for traceability. No tree-walking code needed.
- **Threshold filter over discard.** Min attendance threshold is a view filter in the HTML dashboard, not data destruction. CSV export always contains all records. Fleeting Birds section shows what's excluded.
- **Avg attendance computed from filtered rows.** Was previously using static metadata from Teams CSV header, which ignored the threshold filter.
- **Report title in config.** `report_title` field in YAML, CLI `--title` overrides. Fallback chain: CLI → config → org_name → default.
- **UTF-16 handling.** Teams on Windows sometimes exports UTF-16 LE. Parser now tries utf-8-sig → utf-16 → latin-1 fallback.
- **Real org configs gitignored.** `config/config-census.yaml` kept out of repo. Synthetic `config/config.yaml` stays tracked as example.
